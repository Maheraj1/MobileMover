# Mobile Tabletop Navigator

**A Unity 2D Game - Simple Obstacle Navigation with Battery Management**

## Description

Control a mobile phone sitting on a table using WASD keys in a 2D top-down view. Navigate the
phone through a series of obstacles placed on the tabletop. Your movement consumes battery, and
you must reach a charging point before your battery completely drains!
## Project Structure

*   `Assets/`: Contains all game assets (sprites, textures, scripts, etc.)
    *   `Scripts/`: C# scripts for game logic.
    *   `Sprites/`: 2D sprite images.
    *   `Textures/`: Textures for the sprites.
    *   `Prefabs/`: Reusable game objects (e.g., the phone prefab).
    *   `Scenes/`: The game's scenes (e.g., MainScene).
